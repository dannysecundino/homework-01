# Relatório de Estatística

Relatório do homework de Estatística em LaTeX.

## Dependências

No Ubuntu, instale o LaTeX e os pacotes mais comuns com:

```bash
sudo apt update
sudo apt install texlive-latex-extra texlive-fonts-recommended texlive-lang-portuguese
```

## Gerar o PDF

Entre na pasta `relatorio` e execute:

```bash
pdflatex main.tex
```

O arquivo `main.pdf` será gerado na mesma pasta.

Se o relatório possuir referências bibliográficas ou índice, pode ser necessário executar o comando mais de uma vez.
